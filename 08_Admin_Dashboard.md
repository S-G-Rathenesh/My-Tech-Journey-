# 08_Admin_Dashboard.md - E'xploreMe Admin Dashboard

## Route: `/admin`

### Key Features
1. **Projects Management**: Add, update, or hide projects displayed in the 3D world.
2. **Contact Messages**: Read and archive visitor inquiries received from the Communication Nexus.
3. **Telemetry & Analytics**: Overview of zone traffic (Main Plaza, AI Lab, Mobile Hub, Future Portal).
4. **Cyber Theme Customizer**: Toggle neon ambient colors, fog density, and bloom intensity live.
