# 05_Player_Controller.md - E'xploreMe Player Controller

## Desktop Controls
- **WASD / Arrow Keys**: Smooth movement relative to camera angle.
- **Mouse Drag**: Camera orbit & free look.
- **Shift**: Sprint boost (1.8x speed boost with cyan trail effect).
- **Space**: Jump mechanics with gravity decay.
- **E**: Interact with highlighted 3D pedestals / buildings.
- **ESC / M**: Toggle Menu / Fullscreen overview.

## Mobile Controls
- **Left Virtual Joystick**: Dynamic touch joystick for smooth 360 movement.
- **Right Screen Drag**: Smooth camera yaw/pitch pan.
- **Action Buttons**: Floating jump button & context interaction button.
