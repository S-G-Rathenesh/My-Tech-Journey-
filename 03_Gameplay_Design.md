# 03_Gameplay_Design.md - E'xploreMe Gameplay Design

## Core Loop
1. **Spawn**: Player arrives at the Main Plaza Monolith.
2. **Exploration**: Movement across 5 distinct cyber zones using keyboard/mouse or mobile touch joystick.
3. **Proximity Trigger**: Approaching a project pedestal triggers proximity highlight and interaction prompt.
4. **Inspection**: Interacting opens the Glassmorphic Project Modal with live links, code repositories, video demos, and APK downloads.
5. **Guidance**: EXA AI Guide floating companion assists with navigation and answers questions about developer milestones.
6. **Communication**: Reaching the Communication Nexus allows direct contact submission to Firebase.

## Sound & Atmosphere Design
- Procedural Web Audio synthesized Cyber ambient drone.
- Interactive sound effects (SFX) for UI clicks, zone entry chime, jump impact, and EXA voice synthesized notes.
