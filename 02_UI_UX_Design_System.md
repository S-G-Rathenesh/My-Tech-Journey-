# 02_UI_UX_Design_System.md - E'xploreMe Design System

## Theme: Cyber Purple

### Color Palette
- **Background**: Space Black (`#05050A`, `#0B0B14`)
- **Primary Accent**: Neon Purple (`#A855F7`, `#8B5CF6`)
- **Secondary Accent**: Electric Cyan (`#06B6D4`, `#22D3EE`)
- **Highlight Magenta**: Cyber Pink (`#EC4899`, `#F43F5E`)
- **Glass Panel Surface**: `rgba(15, 12, 30, 0.75)` with `backdrop-filter: blur(16px)`
- **Borders**: Glowing gradient borders `rgba(168, 85, 247, 0.4)`

### Typography
- **Primary Header Font**: Orbitron / Syncopate / System Cyber sans-serif
- **Body Font**: Inter / Roboto / System UI

### UI Components
1. **HUD Overlay**: Minimap radar, objective banner, sound toggle, EXA assistant button, system time indicator.
2. **Glassmorphic Modals**: Blurred translucent panels with glowing neon borders, tabbed content, interactive live frames.
3. **Interactive Prompt**: Floating 3D/2D badge ("Press [E] to Interact" / "Tap to Inspect") appearing when approaching project pedestals.
4. **Mobile Controls Overlay**: Touch virtual joystick, camera touch gesture surface, action buttons (Interact, Jump).
